# Instrucciones del Proyecto

- Cualquier cambio de simulación, fixture, grupos, equipos, partidos o estado visible del Mundial debe reflejarse también en el dashboard HTML.
- Si se actualizan `fixture.md`, `grupos.md`, `equipos/` o `partidos/`, revisar y ajustar `dashboard/` según corresponda.
- Antes de entregar, validar que `dashboard/index.html` + `dashboard/app.js` puedan mostrar el estado actualizado desde los archivos Markdown.
- No dar por terminado un pedido del usuario si el resultado no queda visible en `http://localhost:<puerto>/dashboard/` al servir el repo localmente.
